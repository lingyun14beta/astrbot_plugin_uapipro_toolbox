# 📦 UApiPro-Toolbox 工具箱插件

本插件是为 **AstrBot** 机器人框架开发的综合功能包。它通过集成 [UApiPro](https://uapis.cn) 提供的开放接口，为机器人提供精美的图文交互体验。在未来，我们也将会适配更多接口，尽请期待。

## 💡 核心功能

*   **双模式显示**：默认渲染为高清 HTML 图片卡片，排版美观；支持在设置中一键开启纯文本模式，适应低流量环境。
*   **安全防护架构**：
    *   **防 HTML 注入**：严格转义所有用户输入，阻断恶意脚本探测服务器本地文件 (LFI)。
    *   **SSRF 硬件拦截**：自动判定查询目标的 IP 属性，物理隔离对内网或受限网段的探测。
    *   **隐私脱敏**：系统日志自动屏蔽 Token 密钥，确保运维安全。
*   **磁盘零堆积**：内置临时文件自动销毁机制，图片发送完成后立即删除缓存，不占用服务器磁盘空间。
*   **智能广播系统**：支持定时推送每日新闻总结，具备插件重载避让逻辑，防止重复推送。

## 📂 项目结构

插件采用**“转接器模式”**设计，实现了逻辑与展示的解耦：

```text
astrbot_plugin_uapipro/
├── main.py             # 核心调度：负责指令分发、安全守卫与文件清理
├── _conf_schema.json   # 配置
├── card_renderer.py    # 渲染
├── metadata.yaml       # 插件元数据
├── apis/               # API 矩阵
│   ├── weather.py      # 天气查询模块
│   ├── ipquery.py      # IP 归属地查询模块
│   ├── mcquery.py      # Minecraft 服务器状态查询
│   ├── hitokoto.py     # 一言/语录获取
│   ├── news.py         # 每日新闻摘要获取
│   └── random_img.py   # 随机图片库获取
└── README.md           # 项目说明文档
```

## 🎮 指令清单

| 指令格式 | 功能说明 | 限制与说明 |
| :--- | :--- | :--- |
| **`/u 天气 <城市>`** | 实时天气、今日温差、空气质量及详细生活建议 | 限 40 字符内 |
| **`/u ip <IP/域名>`** | 查询 IP 或域名的地理位置、运营商及网络信息 | 限 150 字符内 |
| **`/u mc <服务器>`** | Minecraft (Java) 服务器在线人数、版本及图标查询 | 禁止查询私有 IP |
| **`/u 一言`** | 随机获取一条精选诗词、动漫台词或名言语录 | 无 |
| **`/u 新闻`** | 获取今日全网 60 秒热点新闻总结图 | 响应约 10-15s |
| **`/u 随机图片`** | 从后台配置的分类库中随机抽取并发送图片 | 根据面板勾选决定 |
| **`/u 帮助`** | 显示此指令说明文档 | 无 |

## ⚙️ 插件设置说明

您可以在 AstrBot Web 面板的“插件配置”中进行全中文可视化设置：

*   **接口密钥 (Token)**: 填入您在 UApiPro 后台获取的专属 Token（可留空）。
*   **随机图片库范围**: **多选下拉框**。支持勾选 `ACG`、`风景`等分类。机器人会仅从您勾选的范围中随机挑选。
*   **指令冷却时间**: 自定义触发间隔（默认 5.0 秒），防止并发刷屏。
*   **定时早报配置**:
    *   **推送开关**: 开启后每天自动执行推送任务。
    *   **具体时间**: 格式为 `HH:MM`。
    *   **推送名单**: 支持多行输入群号或 QQ 号，实现跨平台精准送达。
